# Fonts

Fraunces and Inter, both licensed under the SIL Open Font License 1.1.

Files are the static latin subsets served by Fontsource (which republishes
the Google Fonts files):

- Fraunces — © The Fraunces Project Authors — https://github.com/undercasetype/Fraunces
  - Fraunces-Regular.woff (400), Fraunces-Italic.woff (400 italic),
    Fraunces-SemiBold.woff (600), Fraunces-SemiBoldItalic.woff (600 italic),
    Fraunces-Black.woff (900)
- Inter — © The Inter Project Authors (Rasmus Andersson) — https://github.com/rsms/inter
  - Inter-Regular.woff (400), Inter-Medium.woff (500),
    Inter-SemiBold.woff (600), Inter-Bold.woff (700)

WOFF (not WOFF2), as the Hyper Elements PDF and image renderers require.
The same files, via the Fontsource CDN, are the webfont faces named in the
Page and Document templates.
